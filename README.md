# Sawala Learning Project

Repository ini berisi tentang catatan belajar javascript fundamentals, latihan harian dan hasil praktik/output wajib selama 10 minggu.

## Struktur folder

- **`01-javascript-fundamentals`**
 - `01-variabel-tipe-data`: Belajar mengenai variabel dan tipe data.
 - `02-kondisi-fungsi`: Belajar mengenai kondisi (`if/else`) dan fungsi.
 - `03-object-array`: Belajar dasar data array dan object.
 - `04-looping-array-methods`: Belajar metode array (`map`, `filter`, `reduce`) dan looping.
 - `05-destructuring-spread`: Belajar destructuring dan spread sintaks.
 - `06-es-modules`: Belajar pemisahan kode menggunakan module (`import`, `export`).
 - `mini-project-kalkulator`: output sederhana penjumlahan, pengurangan, perkalian, pembagian.
 - `mini-project-data-siswa`: membuat data siswa dan menampilkan output nya.
 - `mini-project-daftar-produk`: membuat data produk dan pencarian sederhana.

 ## cara menjalankan project mini

 1. Buka terminal di editor (Antigravity, Vscode).
 2. Masuk ke folder project:
    cd 01-javascript-fundamentals/mini-project-daftar-produk
 3. Jalankan file index.js dengan node.js
    node index.js
